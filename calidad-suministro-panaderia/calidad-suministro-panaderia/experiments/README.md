# Experimentos

Cada archivo describe un bloque experimental del proyecto. La intención es que el profesor pueda seguir la lógica del trabajo sin depender únicamente del informe final.

- `experimento_01_reconocimiento_instalacion.md`: baseline, equilibrio/desequilibrio y comparación PicoScope/MyeBox.
- `experimento_02_escenarios_panaderia.md`: G1, G2 y G3 del obrador de panadería.
- `experimento_03_distorsion_armonicos_eventos.md`: cargas no lineales, THD, eventos y transitorios.
- `resumen_medidas.md`: interpretación de la tabla resumen.
