# Documentación técnica

Esta carpeta contiene los documentos base del proyecto:

- `guia_tecnica_calidad_red_electrica.pdf`: fundamentos de seguridad, instrumentación, desequilibrio trifásico, armónicos, potencias no senoidales, resonancia, eventos y criterios UNE-EN 50160.
- `configuraciones_y_metodos_de_analisis.pdf`: configuraciones experimentales, capturas, valores RMS, desfases, frecuencias y tabla resumen de resultados.

Estos documentos sirven como respaldo del informe final y de la web interactiva.
