# Equalyti PQ · Web interactiva

Aplicación React/Vite para presentar el caso C5 de calidad del suministro eléctrico aplicado a una panadería industrial.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Compilar para Netlify/Vercel

```bash
npm run build
```

Después se sube la carpeta `dist/`.
