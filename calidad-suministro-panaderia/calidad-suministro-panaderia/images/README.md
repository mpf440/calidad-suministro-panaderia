# Imágenes y capturas

- `profesor_guidelines/`: capturas de la guía del proyecto proporcionada por el profesor.
- `web_capturas/`: espacio para capturas de la herramienta Equalyti PQ.

Se recomienda añadir aquí capturas de PicoScope y MyeBox exportadas como PNG/JPG para que el repositorio pueda revisarse visualmente sin abrir todos los CSV.
