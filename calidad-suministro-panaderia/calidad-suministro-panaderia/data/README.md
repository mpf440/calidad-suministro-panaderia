# Datos experimentales

Esta carpeta contiene los datos originales y organizados del proyecto.

## Contenido

- `raw/ArchivosPicoScope.rar`: paquete original con las capturas/exportaciones de PicoScope.
- `resumen_medidas.csv`: tabla resumen de tensiones, corrientes, frecuencia, desfase, factor de potencia y potencia aparente extraída del documento de configuraciones.
- `S1_reconocimiento/`: carpeta para medidas de reconocimiento de la instalación.
- `S2_distorsion_armonicos_evento/`: medidas de los tres escenarios del obrador.
- `S3_tiempo_frecuencia_dictamen/`: datos de eventos y análisis tiempo-frecuencia.

## Convención de nombres recomendada

```text
G1_L1_tension.csv
G1_L1_corriente.csv
G1_neutro_corriente.csv
G1_alimentacion_trifasica.csv
```

El objetivo es que cualquier CSV pueda identificarse sin abrirlo.
